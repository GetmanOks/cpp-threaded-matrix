# Умножение матриц в несколько потоков

Консольная программа считает произведение матриц `A (m x n)` и `B (n x k)`. Клетки результата `C = A x B` разбирают `p` одинаковых потоков POSIX (`pthread`). Поток берёт следующую ещё не занятую клетку слева направо по строкам. Пока он её считает, остальные могут взять следующие. Между собой потоки синхронизируются мьютексом. В расчёте каждой клетки есть короткая пауза, чтобы успели поработать все потоки.

Когда свободных клеток не остаётся, поток сообщает главному, что закончил. Главный дожидается всех таких сообщений, печатает `C` и запускает ещё один поток. Тот дописывает результат в конец `protocol.txt`, не затирая прошлые запуски.

## Сборка

Нужен `g++` с поддержкой C++17 и pthread.

Linux:

```bash
make
make test
```

Windows, в терминале, где доступен MinGW (MSYS2 UCRT64):

```powershell
mingw32-make
mingw32-make test
```

На Windows программа собирается статически: рядом не нужны библиотеки MinGW. На Linux флаг `-static` не ставится. Сборка сама ставит каталог компилятора MinGW первым в пути поиска, чтобы не подхватить чужие копии тех же библиотек, если они уже стоят на компьютере.

`make test` собирает отдельную программу и прогоняет проверки класса `Matrix`, многопоточного умножения и записи протокола. В конце должна быть строка `Все тесты прошли`.

`mingw32-make clean` останавливает уже запущенные `matrix.exe` и `test_matrix.exe`, затем удаляет их. Пока программа ждёт ввод в другом окне, новая сборка не может записать файл поверх и падает с `Error 1`.

Удалить собранные файлы и протокол:

```bash
make clean
```

На Windows то же самое через `mingw32-make clean`.

## Запуск

Размеры и матрицы читаются из стандартного ввода. Первая строка — четыре целых числа:

```text
m n k p
```

`m` — число строк `A`, `n` — число столбцов `A` и строк `B`, `k` — число столбцов `B`, `p` — число рабочих потоков. Дальше идут `m` строк матрицы `A` по `n` чисел и `n` строк матрицы `B` по `k` чисел.

Готовый пример лежит в `sample.in`:

```bash
./matrix < sample.in
```

Windows:

```powershell
cmd /c "matrix.exe < sample.in"
```

Для этих данных

```text
A = | 1 2 |    B = | 5 6 |
    | 3 4 |        | 7 8 |
```

программа печатает

```text
19 22
43 50
```

и дописывает тот же результат в `protocol.txt`.

Числа можно ввести и вручную: запустить `matrix` или `matrix.exe` без перенаправления и набрать их с клавиатуры.

## Состав

| Файл | Зачем |
| --- | --- |
| `main.cpp` | Чтение ввода, запуск расчёта, печать результата, поток протокола |
| `matrix.hpp`, `matrix.cpp` | Класс матрицы: размеры, клетки, произведение в одном потоке |
| `multiply.hpp`, `multiply.cpp` | Параллельный расчёт клеток, мьютекс и сообщения о завершении |
| `protocol.hpp`, `protocol.cpp` | Текст протокола и дописывание его в файл |
| `pause.hpp` | Пауза внутри расчёта |
| `test_matrix.cpp` | Тесты |
| `sample.in` | Пример входных данных |
